Data extraction

  • Structured sources (built). Cleveland's API, Getty's dealer records and Wikidata for place coordinates.
  • Text and scans (planned). Free-text paragraphs, scanned auction catalogues and handwritten ledgers.
  • Rules first. Every value points to its exact source words; AI only where rules fail.

Map and chart visualizer

  • How. React draws the SVG; D3 supplies the scales and the map projection.
  • Tools. Vite to build, Vitest to test, headless Chrome to check the screens.
  • Libraries. React 19, TypeScript 7, D3 7, topojson.

Decision making (name matching)

  • Algorithm. RapidFuzz name score, checked against life dates and shared artworks.
  • Ranking. Three bands (strong, possible, weak), each with plain reasons. No learned model, no fake precision.
  • A person decides. Accept or reject; the Claude API is planned for hard names only.

Planned pipeline for scanned documents

From the PRD and proposal: auction catalogue PDFs with OCR, one or two real pages, checked against Getty's transcription. No OCR tool has been chosen yet.
